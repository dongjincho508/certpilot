# 위협 모델 (SECURITY)

## 1. 신뢰 경계

- 관리 서버(내부) ↔ 대상 서버(SSH)
- 관리 화면 ↔ 관리 서버(HTTPS)
- 관리 서버 ↔ 테스트 환경(격리)

## 2. 위협 목록

| 위협 | 영향 | 대응 |
|---|---|---|
| SSH 세션 가로채기 | 인증 정보 유출 | ssh-agent, 개인키 파일 미저장 |
| 호스트 키 변경 | MITM | TOFU + 변경 탐지 시 조회 차단 |
| 인증서 변조 | 상태 오인 | 조회 전 SHA-256 해시 비교 |
| 권한 상승 | 읽기 권한 초과 | 전용 읽기 전용 계정, sudo 불필요 |
| 감사 로그 조작 | 감사 추적 무력화 | WORM, 관리자 전용 열람 |
| 키스토어 파싱 시 키 접근 | 키 유출 | 인증서만 추출, 개인키 미접근 |
| 패스워드 인증 | 인증 우회 | 패스워드 미지원 |

## 2. 완화 조치

- SSH: 개인키 + ssh-agent
- 호스트 키: TOFU + 변경 탐지 시 차단
- 인증서: SHA-256 해시 비교
- 계정: 전용 읽기 전용, sudo 불필요
- 감사 로그: WORM(append-only + SHA-256 해시 체인), 보존 1년, 관리자만 열람
- 키스토어: 인증서만 추출, 개인키 미접근 + 접근 시도 감사 로그
- 인증: 패스워드 미지원

## 3. 독립 검토

- PRD v0.3 정정 사항 (B-1~B-6, H-1~H-10, Q-AUDIT/관리 화면·인증) 반영 확인
- 보안 설계 검증: 위협 모델 문서 작성
