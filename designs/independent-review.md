### 4.1 권고 사항 — 설계 단계 반영 완료

1. **감사 로그 WORM 구현 방법론** → 반영 완료: WORM은 append-only 파일 + SHA-256 해시 체인(메타데이터 해시 트리) 방식으로 구체화. 객체 저장소 사용 시 versioning + delete 금지.
2. **허용 명령 목록 구체화 (B-5)** → 반영 완료: infra.md §4에 고정 읽기 전용 명령 목록(`cat`/`head`/`tail`, `openssl x509`, `ss -tlnp`, `openssl s_client`, `getent`) 정의. 셸 해석·파이프라인·sudo 금지, 허용 목록 외 시도는 '원격 명령 실행 실패'로 분류.
3. **포트 기반 조회 실패 구분 (B-3)** → 반영 완료: infra.md §5에 포트 열거(LISTEN만), TLS SNI/TLS 버전 지정 핸드셰이크, 실패 구분(연결 시간 초과/핸드셰이크 실패/인증 실패) 명시.
4. **키스토어 보존 방법론 (B-4)** → 반영 완료: pki.md §2.5에 접근 통제·접근 시도 감사 로그 명시. 메타데이터만 확인 + 내용 파싱 제외.
