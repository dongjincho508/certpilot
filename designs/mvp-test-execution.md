# MVP 검증 시나리오 실행 계획 (QA_SRE)

**대상**: CertPilot MVP (PRD v0.3, 릴리스 승인 완료)
**작성일**: 2026-10-21
**작성자**: QA_SRE (Owner 승인 후)
**검증 환경**: 격리 테스트 서버 (신규 VM/컨테이너)

---

## 1. 검증 개요

- **검증 목표**: MVP가 PRD v0.3 요구사항을 충족하는지 확인 (AC-1~AC-10)
- **검증 환경**: 격리 테스트 서버 (운영 서버와 완전 분리)
- **검증 방식**: 수동/자동 테스트 실행 + 결과 기록
- **통과 기준**: 모든 AC 항목 검증 + KPI 측정 기준 충족

---

## 2. 테스트 데이터 준비

### 2.1 테스트 인증서 세트

| 상태 | 파일 | 내용 | 기대 검증 |
|---|---|---|---|
| 정상 | `test-server.crt` | 유효 (30일+) | 정상 상태 |
| 만료 임박 | `test-server-expired-30.crt` | 30일 남김 | 경고 |
| 만료 | `test-server-expired-60.crt` | 60일 전 만료 | 만료 |
| 미발견 | `nonexistent.crt` | 경로 존재하나 없음 | AC-5 |
| 확인 필요 | `corrupt.crt` | 깨진 파일 | AC-5 |
| 체인 | `test-chain.crt` | 리프+중간CA+루트 | 체인 상태 분류 |

### 2.2 테스트 경로 구성

```
/opt/certpilot/test/
├── certs/
│   ├── test-server.crt (유효)
│   ├── test-server-expired-30.crt (만료 임박)
│   ├── test-server-expired-60.crt (만료)
│   ├── corrupt.crt (깨진 파일)
│   ├── nonexistent.crt (미발견)
│   └── chain/
│       ├── leaf.crt
│       ├── intermediate.crt
│       └── root.crt
├── forbidden.txt (조회 금지 경로 테스트)
└── logs/ (검증 결과 저장)
```

## 3. 테스트 시나리오 (AC-1 ~ AC-10)

### 4.1 AC-1: 서버 식별 정보 목록

| 항목 | 값 |
|---|---|
| 검증 항목 | 서버 등록 → 목록 조회 시 서버명·호스트명/IP 표시 |
| 입력 | `test-server` (테스트 서버) |
| 예상 결과 | 서버명·호스트명·IP가 목록에서 확인 |
| 검증 방법 | `GET /servers` 엔드포인트 조회 |

### 4.2 AC-2: SSH 연결 성공/실패 + 원인 유형

| 항목 | 값 |
|---|---|
| 검증 항목 | SSH 연결 성공/실패 구분, 원인 유형 표시 |
| 입력 | 정상 SSH 서버, 실패 SSH 서버 (PORT 22/2222) |
| 예상 결과 | 성공·실패 구분, 원인 유형 표시 |
| 실패 유형 | DNS 실패, 연결 시간 초과, 인증 실패, 호스트 키 불일치 |

### 4.3 AC-3: 인증서 표시 항목

| 항목 | 값 |
|---|---|
| 검증 항목 | CN/SAN, 발급자, 주체, 유효 시작일, 만료일 표시 |
| 입력 | 정상 인증서 |
| 예상 결과 | CN/SAN·발급자·주체·만료일 표시 |
| 검증 방법 | 표시 값과 원본 인증서 대조 |

### 4.4 AC-4: 잔여 일수 + 상태 분류

| 항목 | 값 |
|---|---|
| 검증 항목 | 잔여 일수 계산, 상태 분류 |
| 입력 | 유효/만료 임박/만료 인증서 |
| 예상 결과 | floor·0 클램프 적용, 상태 분류 |
| 판정 기준 | `now >= notAfter` → 만료, `now >= notAfter-T` → 만료 임박 |

### 4.5 AC-5: 실패/미발견/확인 필요

| 항목 | 값 |
|---|---|
| 검증 항목 | 조회 실패, 인증서 미발견, 확인 필요 |
| 입력 | nonexistent.crt, corrupt.crt |
| 예상 결과 | 정상으로 표시되지 않음 |

### 4.6 AC-6: 마지막 조회 시각·결과

| 항목 | 값 |
|---|---|
| 검증 항목 | 시각 갱신, 실패 시각 별도 기록 |
| 입력 | 정상 조회, 실패 조회 |
| 예상 결과 | 성공 조회만 갱신, 실패 시각 별도 기록 |

### 4.7 AC-7: 인증서·개인키 변경 없음

| 항목 | 값 |
|---|---|
| 검증 항목 | 조회 전후 SHA-256 해시 비교 |
| 입력 | 정상 인증서 |
| 예상 결과 | 해시 일치 (변경 없음) |

### 4.8 AC-8: 이력 비교 범위

| 항목 | 값 |
|---|---|
| 검증 항목 | 이력 비교 방법 |
| 예상 결과 | P1 이관 확인 |

### 4.9 AC-9: KPI 3개

| KPI | 목표 | 측정 방법 |
|---|---|---|
| 전체 조회 성공률 | ≥99% | 감사 로그 기반 주간 측정 |
| 만료 누락 | 0건 | 만료 상태인데 조회 누락 확인 |
| 평균 완료 시간 | ≤10분 | 전체 조회 소요 시간 측정 |

### 4.10 AC-10: 감사 로그 무결성

| 항목 | 값 |
|---|---|
| 검증 항목 | WORM 저장, 주기적 무결성 검증 |
| 입력 | 감사 로그 |
| 예상 결과 | 변조 감지 시 알림 |

## 4. 검증 실행 절차

### 4.1 1단계: 환경 검증

| 단계 | 작업 | 성공 기준 |
|---|---|---|
| 1.1 | 테스트 서버 SSH 접속 | 접속 성공 |
| 1.2 | 테스트 인증서 존재 확인 | 파일 존재 |
| 1.3 | 방화벽 확인 | SSH(22)만 허용 |
| 1.4 | SSH 서버 실행 확인 | 서비스 활성 |

### 4.2 2단계: 기본 조회 검증 (AC-1 ~ AC-6)

| 단계 | 작업 | 예상 결과 |
|---|---|---|
| 2.1 | 서버 등록 | 등록 성공 |
| 2.2 | SSH 연결 확인 | 성공/실패 구분 |
| 2.3 | 인증서 표시 항목 대조 | 값 일치 |
| 2.4 | 잔여 일수 계산 | floor·0 클램프 적용 |
| 2.5 | 실패/미발견/확인 필요 상태 분류 | 정상 아님 |
| 2.6 | 마지막 조회 시각·결과 | 성공 갱신, 실패 분리 |

### 4.3 3단계: 보안 검증 (AC-7, AC-10)

| 단계 | 작업 | 예상 결과 |
|---|---|---|
| 3.1 | 조회 전후 SHA-256 해시 비교 | 해시 일치 |
| 3.2 | 감사 로그 저장 확인 | 로그 저장 확인 |
| 3.3 | WORM 무결성 검증 | 무결성 확인 |
| 3.4 | 변조 감지 시 알림 | 알림 발생 |

### 4.4 4단계: KPI 측정 (AC-9)

| KPI | 목표 | 현재 측정값 |
|---|---|---|
| 전체 조회 성공률 | ≥99% |  |
| 만료 누락 | 0건 |  |
| 평균 완료 시간 | ≤10분 |  |
