# 인프라 연동 설계 (INFRA_CONNECTOR)

## 1. SSH 연동

- **지원 버전**: OpenSSH 7.0 이상
- **기본 포트**: 22 (비표준 포트는 등록 시 필수)
- **인증**: 개인키 + ssh-agent (패스워드 미지원)
- **호스트 키**: TOFU + 변경 탐지 시 조회 차단
- **연결 판정**: 인증 성공까지 세션 수립 (TCB 개방만으로 판정 안 함)

## 2. 연결 타임아웃/재시도

- **타임아웃**: 10초
- **재시도**: 2회 + 지수 백오프
- **실패 분류**: DNS 실패, 연결 시간 초과, 인증 실패, 호스트 키 불일치, 접속 권한 거부, 원격 명령 실행 실패 (6종, 미분류 없음)

## 3. 실패 처리

- DNS 실패·연결 시간 초과: **재시도** (최대 2회, 지수 백오프)
- 인증 실패·접속 권한 거부·호스트 키 불일치: **즉시 실패** (재시도 없음)
- 원격 명령 실행 실패: **원격 명령 실행 실패**로 분류 (허용 명령 목록 밖 실행 시도 포함)

## 4. 원격 명령 허용 목록 (B-5) — 고정 읽기 전용

대상 서버에서 실행 가능한 명령을 고정된 읽기 전용 명령 집합으로 한정한다. 셸 해석·파이프라인·쓰기·sudo는 금지하며, 허용 목록 밖의 명령 시도는 **원격 명령 실행 실패**로 분류한다.

| 용도 | 허용 명령 | 비고 |
|---|---|---|
| 파일 내용 확인 | `cat`, `head`, `tail` | 인증서 파일·경로 파일 읽기 |
| 인증서 요약 (PEM) | `openssl x509 -noout -dates -subject -issuer -ext subjectAltName` | |
| 인증서 요약 (DER) | `openssl x509 -inform der -noout -dates -subject -issuer` | |
| TCP 포트 열거 | `ss -tlnp` | LISTEN 포트만 |
| TLS 핸드셰이크 | `openssl s_client -connect <host>:<port> -servername <SNI> -tls1_2` | |
| DNS 확인 | `getent hosts` | |

## 5. 포트 기반 조회 (B-3) — 실행 중 서비스

포트 기반 조회의 실패 구분은 다음과 같이 구체화한다.

- 포트 열거: 운영체제가 노출한 LISTEN 포트만 수집 (find/전체 탐색 금지)
- 핸드셰이크: 각 LISTEN 포트에 대해 TLS SNI·TLS 버전을 지정해 `openssl s_client`로 핸드셰이크를 시도
- 실패 구분: 연결 시간 초과 / 핸드셰이크 실패 (SNI·TLS 버전 불일치, 인증서 미제공) / 인증 실패
- 방화벽 개방 요구는 운영·관리망 환경에서만 수행하며, 격리 테스트 환경에서 사전 검증

- 제외: bastion, 컨테이너, 전체 탐색, CRL/OCSP
