# 테스트 전략 (QA_SRE)

## 1. 격리 테스트 환경

- **구축**: 신규 VM/컨테이너 기반
- **목적**: 운영 서버 미사용, 인증서와 파일 배치 인증서 모두 발견
- **조성**: QA_SRE (Docker/로컬 VM), 인증서 세트 PKI_ENGINE

## 2. 인증서 세트

- **최소 구성**: 유효·만료 임박·만료·미발견·확인 필요 각 1건 이상
- **정상**: 1대 (실패 1대), 상태별 샘플 인증서 세트
- **테스트**: 운영 서버 미사용, 격리 환경

## 3. KPI

- **전체 조회 성공률 ≥99%**
- **만료 누락 0건**
- **평균 조회 완료 시간 ≤10분**

## 4. 테스트 범위

- 정상 조회, 실패 조회, 상태별 샘플 인증서
- 수동 갱신, 필터/정렬, 감사 로그 열람

## 5. 릴리스 게이트

- 결정 잔여 0건
- AC-1 ~ AC-10 전항 통과
- 역할 검토 + 용어집 동기화
- 보안·아키텍처 항목: 독립 검토 후 오너 승인
