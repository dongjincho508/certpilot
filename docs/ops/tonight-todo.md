## C. VM 이 준비되면 (당일 순서)
1. [설치 매뉴얼](vm-install-and-test.md) 1~6단계: OS → Docker → 감시 스택 기동 → nginx HTTPS (합격 기준은 각 단계 끝)
2. 7~8단계: certdeploy 설치, SSH 키 → 대상 서버 준비(`deploy` 계정)
3. 9단계: `validate` → `preflight` → `csr` → CA 제출 → `import --dry-run` → canary `deploy`
4. [테스트 시나리오](test-scenarios.md) T-01~T-13 수행·결과표 작성
5. 실패하면 `diagnose --out` 번들과 함께 시험 ID·명령·기대/실제 결과를 전달 → 수정 후 같은 시험 재실행 ([디버깅 가이드](debugging.md))

## D. 하지 말 것
- 개인키·키스토어·`.env`·SMTP 비밀번호·웹훅 URL을 채팅·메일·문서에 붙여 넣지 않는다(`diagnose` 번들은 마스킹되지만 그래도 확인 후 전달)
- 운영 서버에 첫 시험을 하지 않는다 — 항상 시험용 1대(canary) → 나머지
- SELinux 를 끄지 않는다(막히면 `ausearch -m avc` 결과를 전달)
- VMware 스냅샷을 오래 두지 않는다(개인키 포함)
