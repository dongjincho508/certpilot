# 미확정·이월 항목

PRD 는 "결정 잔여 0건"이지만, 아래는 **설계·구현으로 넘겨진 항목**이다. 결정 전까지 "완료"로 표기하지 않는다.

## A. 오너/보안 결정이 필요한 항목

| # | 항목 | 현재 상태 | 선택지·권고 |
|---|---|---|---|
| O-1 | **WORM 저장소 수준 불변성** (권고 1) | 해시 체인으로 변조 *탐지*만 | (a) 객체 저장소 Object Lock (b) 파일 `chattr +a` (c) 외부 로그 서버 전송. 권고: 운영 인프라 확정 후 (a)/(c) |
| O-2 | **감사 로그 원문 암호화·복호화 권한** (S-7) | `raw_error` 평문(관리자 전용) | 봉투 암호화(KMS/Vault 키) 도입. 키 관리 결정 필요 |
| O-3 | **S-1 장기 보관 키 저장소** | ssh-agent 만 사용, 앱은 키 미보관 | ssh-agent 전용 유지(회전은 운영 절차) vs Vault/KMS 보관 |
| O-4 | **SSH 알고리즘 범위** (Q-SSHVER) | paramiko 기본값 | 허용 KEX/MAC/Cipher 목록을 보안 검토로 확정 |
| O-5 | **Q-KEYSTORE 독립 검토** | 파싱 제외(B-4)로 구현 | 실제 독립 검토자 필요 (현재 검토는 단일 모델 역할 분리) |
| O-6 | **보관 1년·파기 증명서** | 미구현 | 삭제 승인 워크플로·증명서 양식 결정 |
| O-7 | **비밀번호 변경 주기·유출 계정 차단** | 미구현 | 주기(예: 90일) 확정, 유출 목록 소스 결정 |

## B. 구현 이월 (결정 불필요)

| # | 항목 | 비고 |
|---|---|---|
| I-1 | KPI 집계 리포트 (AC-9) | 감사 로그 `scan` 이벤트로 성공률·소요 시간 산출 |
| I-2 | 주기적 감사 무결성 검증 + 변조 알림 (AC-10) | 스케줄러·알림 채널 필요(알림은 P1) |
| I-3 | 전체 조회 비동기 작업 큐 | 1,000대 확장 시 HTTP 타임아웃 회피. `POST /scan` → 202 + 작업 조회 |
| I-4 | 로그인 시도 IP 단위 제한 | 현재는 계정 단위 잠금만 |
| I-5 | 감사 로그 `write` 의 마지막 해시 읽기가 O(n) | 항목 수 증가 시 마지막 해시 캐시 |
| I-6 | UI: 비밀번호 변경 화면 | API(`POST /auth/password`)는 구현됨 |
| I-7 | 실제 OpenSSH 서버 대상 검증 | 현재는 프로세스 내 paramiko 서버만. CI 에 sshd 컨테이너 서비스 추가 권장 |
| I-8 | 시작 시 최초 관리자 미설정 경고 외 부트스트랩 절차 문서화 | |

## C. 문서 정합성 메모

- PRD 본문은 승인본이므로 수정하지 않았다. 본 저장소의 설계 결정(DD-1~DD-7)은 [ARCHITECTURE](ARCHITECTURE.md) 에 기록했고, PRD 와 충돌하면 오너 승인 후 PRD 개정으로 반영한다.
- `docs/archive/` 는 현재 구현과 맞지 않는 과거 계획(CI/CD 파이프라인, 격리 VM 테스트 계획, 통과 선언 등)이다. 기준 문서가 아니다.
