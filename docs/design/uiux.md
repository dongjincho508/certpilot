# UI/UX 설계 (DESIGN)

## 1. 관리 화면

- **메인 화면**: 서버별 인증서 상태 목록
  - 정렬: 위험 순 (만료 > 체인 위험 > 유효 전 > 만료 임박 > 인증서 미발견 > 확인 필요 > 조회 실패 > 정상) → 서버명
  - 필터: 상태, 그룹
  - 수동 갱신: 조회 버튼
- **서버 등록 화면**: 서버명(식별자), 호스트명/IP, SSH 포트, 계정, SSH 인증 방식, 인증서 조회 경로, 경고 기준 T
- **인증서 상세 화면**: 식별 정보, 발급자, 주체, CN/SAN, 유효 시작일, 만료일, 체인, 상태
- **감사 로그 화면**: 관리자만 열람 (WORM, 보존 1년)

## 2. 권한 모델 (RBAC)

- **관리자**: 서버 등록·삭제·설정 변경, 사용자·역할 관리, 감사 로그 열람
- **운영자**: 조회 실행, 현황 확인, CSV 내보내기
- **분리**: 등록 수행과 조회 열람 분리

## 3. 표시 항목

- 식별 정보, 발급자, 주체, CN/SAN (다중 시 목록)
- 유효 시작일, 만료일, 상태
- 실패 원인 (분류된 6종과 조치 방향만)

## 4. 오류 처리

- 실패 원인은 분류된 원인만 표시, 원문 메시지는 감사 로그에만 기록
- 계정명·키 지문·원격 명령 원문 노출 금지

## 5. 국제화/시각

- 한국어 단일
- 시각: UTC ISO 8601 (YYYY-MM-DDTHH:MM:SSZ)
