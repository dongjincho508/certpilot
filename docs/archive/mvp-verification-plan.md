# MVP 검증 절차 계획 (QA_SRE)

**대상**: CertPilot MVP (PRD v0.3, 릴리스 승인 완료)
**작성일**: 2026-10-21
**작성자**: QA_SRE

---

## 1. 검증 개요

- **검증 목표**: MVP가 요구사항을 충족하는지 확인 (AC-1~AC-10)
- **검증 환경**: 격리 테스트 환경 (신규 VM/컨테이너 기반)
- **검증 방식**: 수동/자동 테스트 실행 + 결과 기록
- **제한 사항**: 운영 서버 미사용, 운영 데이터에 영향 없음

---

## 2. 격리 테스트 환경 (QA_SRE)

### 2.1 환경 구성

| 항목 | 구성 |
|---|---|
| 테스트 서버 | 신규 VM/컨테이너 (운영 서버 미사용) |
| SSH 서버 | OpenSSH 7.0+ (기본 포트 22, 비표준 포트 2222 테스트) |
| 인증서 세트 | PEM/PKCS#12/JKS |
| 계정 | 전용 읽기 전용 계정 (sudo 불필요) |
| 네트워크 | 화이트리스트 기반 경로 접근 |

### 2.2 인증서 세트 구성

| 상태 | 인증서 | 검증 목적 |
|---|---|---|
| 정상 | 유효 인증서 (30일+ 잔여) | KPI 성공률 측정 |
| 만료 임박 | 30일 이내 만료 | 경고 기준 검증 |
| 만료 | 이미 만료된 인증서 | AC-4 상태 분류 |
| 미발견 | 경로 존재하나 인증서 없음 | AC-5 검증 |
| 확인 필요 | 형식 오류/필수 필드 누락 | AC-5 검증 |

### 2.3 테스트 계정 준비

- **전용 읽기 전용 계정**: 조회용 (sudo 불필요)
- **TOFU**: 최초 접속 시 신뢰, 호스트 키 변경 탐지 시 차단
- **자격증명**: 암호화 저장소 보관 (회전 없음 — 테스트용)

## 3. 테스트 시나리오 (AC-1 ~ AC-10)

| AC | 검증 항목 | 테스트 시나리오 | 예상 결과 |
|---|---|---|---|
| AC-1 | 서버 식별 정보 목록 | 서버 등록 → 목록 조회 | 서버명·호스트명/IP 표시 |
| AC-2 | SSH 연결 성공/실패 + 원인 유형 | 정상 SSH / 실패 SSH 각각 조회 | 성공·실패 구분, 원인 유형 표시 |
| AC-3 | 인증서 표시 항목 | 인증서 조회 → 표시 값 대조 | CN/SAN·발급자·주체·만료일 표시 |
| AC-4 | 잔여 일수 + 상태 분류 | 만료 임박/만료/정상 인증서 조회 | floor·0 클램프 적용, 상태 분류 |
| AC-5 | 실패/미발견/확인 필요 | 미발견/형식오류/필수필드누락 | 정상으로 표시되지 않음 |
| AC-6 | 마지막 조회 시각·결과 | 조회 → 시각 갱신 확인 | 성공 조회만 갱신, 실패 시각 별도 기록 |
| AC-7 | 인증서·개인키 변경 없음 | 조회 전후 SHA-256 해시 비교 | 해시 일치 (변경 없음) |
| AC-8 | 이력 비교 범위 | 이력 비교 방법 확인 | P1 이관 확인 |
| AC-9 | KPI 3개 | 전체 조회 성공률·만료 누락·평균 완료 시간 측정 | ≥99% / 0건 / ≤10분 |
| AC-10 | 감사 로그 무결성 | WORM 저장 + 주기적 무결성 검증 | 변형 감지 시 알림 |

## 4. 검증 실행 절차

### 4.1 1단계: 환경 검증

1. 테스트 서버 SSH 연결 확인
2. 계정 인증 확인 (TOFU)
3. 경로 화이트리스트 확인
4. 테스트 인증서 세트 준비 확인

### 4.2 2단계: 기본 조회 검증 (AC-1 ~ AC-6)

1. 서버 등록 (AC-1)
2. SSH 연결 성공/실패 확인 (AC-2)
3. 인증서 표시 항목 대조 (AC-3)
4. 잔여 일수 계산 (AC-4)
5. 실패/미발견/확인 필요 상태 분류 (AC-5)
6. 마지막 조회 시각·결과 확인 (AC-6)

### 4.3 3단계: 보안 검증 (AC-7, AC-10)

1. 조회 전후 SHA-256 해시 비교 (AC-7)
2. 감사 로그 저장 확인 (AC-10)
3. WORM 무결성 검증
4. 변조 감지 시 알림 확인

### 4.4 4단계: KPI 측정 (AC-9)

1. 전체 조회 성공률 측정 (목표 ≥99%)
2. 만료 누락 건수 측정 (목표 0)
3. 평균 완료 시간 측정 (목표 ≤10분)
