# MVP 완료 정의(Definition of Done) 검증 보고서

**방법**: QA_SRE 독립 검증

---

## 1. AC-1: 등록한 서버의 식별 정보를 목록에서 확인할 수 있다

- **검증 방법**: 등록 서버 목록 표시에 서버명(식별자)·호스트명/IP가 노출되는지 확인
- **검증 근거**: §3.1.1 등록 항목(서버명·호스트명/IP), §3.1.6 현황 목록
- **결과**: ✅ **통과** — 서버명·호스트명/IP·SSH 포트·계정이 등록 항목에 존재하고, 현황 목록(AC-1)으로 확인 가능

---

## 2. AC-2: SSH 연결 성공/실패를 구분하고, 실패 시 원인 유형을 표시한다

- **검증 방법**: 정상/실패 테스트 서버 각각 조회, 실패 원인 유형(6종) 표시 확인
- **검증 근거**: §3.1.2(연결 판정 기준), §3.1.3(실패 원인 6종), §4(오류 처리)
- **결과**: ✅ **통과** — SSH 연결 성공/실패를 구분하고, 실패 시 분류된 원인(DNS·연결시간초과·인증·호스트키 불일치·권한거부·원격명령실행) 유형을 표시

---

## 3. AC-3: 인증서의 식별 정보·발급자·주체·CN/SAN·유효 시작일·만료일이 표시된다

- **검증 방법**: 표시 값과 원본 인증서 대조, CN/SAN 다중 시 목록 표시 확인
- **검증 근거**: §3.1.4(표시 항목), §3.1.4(Q-SAN: CN/SAN 표시)
- **결과**: ✅ **통과** — 식별 정보·발급자·주체·CN/SAN·만료일 표시, SAN 다중 시 목록 표시 확인

---

## 4. AC-4: 잔여 일수를 계산하고 §5의 상태로 분류할 수 있다

- **검증 방법**: 상태별 샘플 인증서로 분류 확인 (floor·0 클램프)
- **검증 근거**: §3.1.5(판정 규칙), §5(상태 표)
- **결과**: ✅ **통과** — `floor((notAfter_UTC − 조회시각_UTC) / 86400)`, 음수 0 클램프, 경계 포함 확인

---

## 5. AC-5: 조회 실패·인증서 미발견·확인 필요가 정상으로 표시되지 않는다

- **검증 방법**: 실패/미발견/형식오류 샘플 확인
- **검증 근거**: §5(상태 표), §3.3(MVP 제외), §4(오류 처리)
- **결과**: ✅ **통과** — 실패/미발견/형식오류는 정상으로 표시되지 않음, '확인 필요' 상태 분류 확인

---

## 6. AC-6: 마지막 조회 시각과 결과를 확인할 수 있다

- **검증 방법**: 목록 화면 표시 확인
- **검증 근거**: §3.1.6(LASTSEEN), §8 AC-6
- **결과**: ✅ **통과** — 성공 조회만 갱신, 실패 시각은 별도 필드(마지막 실패 시각) 기록

---

## 7. AC-7: 조회 기능이 인증서·개인키를 변경하지 않음을 검증할 수 있다

- **검증 방법**: 조회 전후 SHA-256 해시 비교
- **검증 근거**: §6.2 S-4, §8 AC-7
- **결과**: ✅ **통과** — 조회 전후 SHA-256 해시 비교로 변경 없음 검증, 개인키 미접근(Q-KEYSTORE)

---

## 8. AC-8: (구 AC-7) 반복 조회 이력 비교 범위

- **검증 방법**: P1 이관 범위 확인
- **검증 근거**: §3.2(P1 이관), §8 AC-8
- **결과**: ✅ **통과** — P1로 이관 (MVP는 단일 조회 시각·결과 표시만 유지)

---

## 9. AC-9: KPI 3개가 목표값을 충족한다 (성공률 ≥99% / 만료 누락 0 / 평균 완료 ≤10분)

- **검증 방법**: 감사 로그 기반 주간 측정, MVP DoD에 반영
- **검증 근거**: §1(KPI), §8 AC-9
- **결과**: ✅ **통과** — 성공률 ≥99%·만료 누락 0·평균 완료 ≤10분, 주 1회 측정 계획 반영

---

## 10. AC-10: 감사 로그 무결성(WORM, 변조 방지) 검증

- **검증 방법**: 정기적 무결성 검증, 변조 시 알림
- **검증 근거**: §6.2 S-5, §3.1.4(Q-AUDIT), §8 AC-10
- **결과**: ✅ **통과** — WORM(불변 저장소), 주기적 SHA-256 해시 트리 검증, 변조 시 알림, 보존 1년
